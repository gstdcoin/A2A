# GSTD compute economics

Only funded, completed and accepted work earns a token reward. Being online, registering a node, submitting a placeholder result or running free/promotional queries does not create withdrawable GSTD.

Accepted paid work allocates **85% to the executor, 10% to the protocol and 5% to the reserve**. The reserve is not an automatic burn or buyback. Claiming or requesting a withdrawal adds no GSTD commission; the custody owner signs the blockchain transfer and pays TON execution costs.

Operators can use earned backed credits for other models through the platform. Availability and price are shown in the [main app](https://app.gstdtoken.com/chat); demand and earnings are not guaranteed. No cost-saving percentage, referral royalty, trust multiplier or token appreciation is promised.

The deployed platform uses a central accounting service and custody wallet. Paid work reserves existing backed credit before execution, captures on acceptance and releases a failed reservation. Free quotas are separate from token balances. A real funded deposit-to-withdrawal mainnet cycle remains an acceptance gate; passing local tests does not establish it.
