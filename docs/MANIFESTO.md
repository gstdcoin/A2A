# GSTD mission: useful compute people can control

GSTD aims to make useful AI compute accessible through a simple application and operator-controlled nodes. People should understand which model handles a request, choose when to send it to another machine, and use earned compute credit for other work.

The practical starting point is local model inference, clear resource limits, signed node identity and a simple paid-work loop. Useful work comes first: only funded, completed and accepted requests may earn GSTD. There is no guaranteed income, token appreciation, passive yield, automatic buyback or 5% burn guarantee.

Independence and broad participation are goals. The current ecosystem still depends on a central platform, accounting service, custody owner and hosting; physical multi-node resilience has not been established. Source is available under the repository license, not as a promise that every device or application is already supported.

Start with the [app](https://app.gstdtoken.com/chat), [node installation](https://gstdtoken.com/nodes) or [current protocol guide](PROTOCOL.md). An [older manifesto](archive/MANIFESTO_2026-10-28.md) is preserved as historical rhetoric, not a product or financial specification.
